Vaultlight is a quiet heist game in three nights at the Meridian Museum. You are the thief crossing one room at a time: guards patrol with vision cones, cameras sweep the floor, lasers blink across the vault corridor, and every second you spend in a cone fills the alarm meter. Grab every loot on the floor — paintings, gems, gold — then slip out through the exit before the alarm hits 100%. Three tools, each with a cost: toss a coin to pull a guard off its patrol, drop a smoke bomb to blind everyone nearby, or hack a camera terminal (three taps, standing exposed) to kill the cameras for 15 seconds. Sneak with Shift to halve how fast the alarm rises. Each floor offers several routes — the main corridor, the side gallery past the rugs, or the quiet gaps between the walls — and the getaway only pays off if you read the cones before you move.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Move with WASD or arrow keys, sneak with Shift, grab loot or hack a terminal with E, toss a coin with Q or right-click, drop smoke with F, pause with P, mute with M. No build step, no network request — `game/` is plain static files.
